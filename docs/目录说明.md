# 目录说明与保留原则

| 目录 | 内容 | 状态 |
| --- | --- | --- |
| `contest/` | 比赛协议、只读探针、无弹控制、数据分析和自检 | 当前比赛适配主线 |
| `io/` | 海康相机；CBoard/CAN 类型仅供开源接口比较 | 相机已实机使用 |
| `tasks/auto_aim/` | YOLOv5、装甲板、PnP、跟踪、预测和开火判断 | YOLO 已实机；后半链路未接入当前入口 |
| `tools/` | 日志、图像、数学、EKF 与弹道工具 | 参与构建 |
| `calibration/` | 棋盘视频标定、独立距离验证、板型记录 | 已现场使用 Python 工具 |
| `configs/` | 本地预览配置 | 不代替 NUC 现场配置快照 |
| `assets/` | 当前 YOLOv5 和数字分类模型 | 当前识别器需要 |
| `tests/` | 相机入口、数据工具与几何回归测试 | 离线检查与现场入口 |
| `docs/调试日记/` | 9、11、14、15 日调试过程 | 提交说明主体 |
| `docs/中期评定/` | 架构、讲解稿、问答和专项实测 | 汇报材料 |
| `evidence/` | 小型报告、控制日志和派生 CSV | 不含大体积原始视频 |
| `src/standard.cpp` | 原开源 CAN 主流程 | 只作架构对照，不参与构建 |

本提交版不包含：`build/`、`output/`、完整现场 AVI/CSV、OpenVINO 本地运行包、车载传输压缩包、
临时日志、Python 缓存和旧的圆点板标定入口。这些内容由 `.gitignore` 阻止误提交。

保留 `Solver/Tracker/Target/Aimer/Shooter` 是为了展示并继续开发完整自瞄链路；文件存在和
编译通过不代表它们已在本车上通过实机验证。
