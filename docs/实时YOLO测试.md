# 用比赛相机实时测试 YOLO

项目已有 `camera_detect_test`：它从海康相机取图，调用 `auto_aim::YOLO::detect()`，并显示检测窗口。检测到模型认识的装甲板时，画面会出现**绿色四角轮廓、类别和置信度**。这是识别预览，不会连接下位机或控制云台。

## 运行

先关闭正在占用相机的 `camera_test` 窗口（按 `q`）。在比赛工程根目录运行：

```bash
cmake --build build --target camera_detect_test -j4
./build/camera_detect_test configs/live_yolo.yaml
```

在 `detection` 窗口按 `q` 结束。模型首次加载可能需要几秒。`configs/live_yolo.yaml` 从演示配置复制，但使用现场相机的 5 ms 曝光、180° 旋转，关闭了传统角点二次修正和自动开火；当前模型为 `assets/yolov5.xml`，设备为 CPU。这个配置只用于识别预览，其余演示设备参数不代表比赛车。

## 怎样理解结果

- 只有相机画面而没有绿色轮廓：相机已正常取图，但 YOLO 没给出**通过筛选**的装甲板结果；普通蓝黄物体或数字牌不一定属于模型训练过的装甲板。
- 有框但位置不准：记下画面和时间，再检查灯条曝光、焦距、模型类别和角点；不要先改云台参数。
- 显示窗的轮廓是四角连线，不是常见的横平竖直矩形框；这四角正是后续位姿解算需要的输入。
- 当前 `min_confidence` 为 0.8，模型还有内部筛选；若比赛靶始终无框，先保存现场录像，再从日志和逐帧结果判断是漏检还是类别不匹配。

此测试只能回答“模型是否在现场画面中检出并定位装甲板”。距离、瞄准角度和命中率仍需要相机标定与后续实车验证。
