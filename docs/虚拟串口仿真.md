# 没有实车时：运行通信与控制自检

提交版保留的是可重复运行的自检程序。它们使用伪终端和模拟反馈检查比赛协议、半帧/多帧解析、20 Hz 发送线程、限幅、目标丢失和看门狗，不访问真实 `/dev/ttyACM*`，也不会请求开火。

## 运行

```bash
cd /path/to/rm自瞄
./运行.sh 自检
```

该命令会配置和编译项目，然后运行全部 CTest。与串口/控制最相关的检查包括：

- `srm_protocol_selfcheck`：18 字节命令编码和 30 字节反馈解析。
- `srm_command_worker_selfcheck`：无弹命令发送线程与伪终端收发。
- `srm_follow_worker_selfcheck`：yaw 跟随的限速、总行程、丢失回正和看门狗。
- `srm_pitch_follow_worker_selfcheck`：pitch 跟随发送线程。
- `srm_xy_follow_worker_selfcheck`：双轴跟随发送线程。

对应源码见[协议编解码](../contest/protocol.cpp)、[yaw 发送线程自检](../contest/follow_worker_selfcheck.cpp)、[pitch 发送线程自检](../contest/pitch_follow_worker_selfcheck.cpp)和[双轴发送线程自检](../contest/xy_follow_worker_selfcheck.cpp)。

## 使用边界

通过自检只说明本机代码在模拟输入下符合既定协议和保护策略。它不能证明真实 USB 权限、固件版本、云台正负方向、相机识别、机械回差、外参、弹道或命中表现；这些结论必须来自实车日志。
