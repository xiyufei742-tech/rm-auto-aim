# 中期评定演示素材

两张截图来自 10 月 14 日原始 AVI 与逐帧 CSV 生成的标注副本；没有重新运行模型，也没有修改原始数据。原始视频和标注视频体积较大，未放入 GitHub 提交版。

| 文件 | 内容 | 汇报时怎么讲 |
| --- | --- | --- |
| `sweep_02_annotated.avi`（另行归档） | 450 帧，约 15 秒。绿色四角为当帧唯一蓝色候选，白十字为画面中心，文字显示回传 yaw。 | “手动扫 yaw 时，目标在图像中移动；CSV 的 449 个有效配对帧拟合出 `+32.35 px/°`。” |
| `rotating_01_annotated.avi`（另行归档） | 900 帧，约 30 秒。`MULTIPLE` 表示有多个蓝色候选；此时没有强行画一个‘唯一目标’框。 | “旋转场景中会同时看到多块装甲板，现有单候选控制会退出，下一步需要跨帧选目标。” |

两段 AVI 的固定播放速度均为 30 FPS，**不能据此声称软件实时处理 30 FPS**；软件取帧时刻和处理年龄应读原 CSV。候选覆盖率不能称为人工标注的检测准确率。提交版可直接展示两张截图，并同时打开[扫描报告](../../../evidence/2026-10-14/sweep_02.report.md)和[旋转靶报告](../../../evidence/2026-10-14/rotating_01.report.md)。
