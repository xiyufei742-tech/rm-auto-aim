# Pitch 手动扫描：局部像素斜率

- 输入：`pitch_sweep_01.csv`，600 帧；有效配对 599 帧。
- 筛除：候选不唯一 0 帧、缺少回传 0 帧、图像或回传过期 0 帧、软件时刻相差超过 100 ms 1 帧、非手动档 0 帧。
- pitch 跨度：7.063°；yaw 同时变化：0.124°；目标纵坐标跨度：229.17 px。
- 一元线性拟合：**dy/dpitch = -32.552 px/°**，R² = 0.9971。

这是当前静止靶、安装与视场附近的经验映射；图像采集时刻和回传接收时刻只是同机软件时钟配对，并非传感器硬件同步。R² 是线性拟合度，不是检测准确率、测距精度或命中率。
